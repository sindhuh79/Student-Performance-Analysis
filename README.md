# Student-Performance-Analysis
  ## Project Overview
This project focuses on analyzing student academic performance using SQL and Data Analytics techniques. The objective is to identify factors affecting student performance, such as attendance, study hours, and assessment scores, through data analysis and visualization.

## Technologies Used
- Python
- SQL
- Data Analytics

## Features
- Student data analysis
- Performance trend identification
- SQL-based data querying
- Data visualization and reporting

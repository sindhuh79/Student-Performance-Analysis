 # Project Summary

## Project Title
Student Academic Performance Analysis Using SQL and Data Analytics

## Objective
The objective of this project is to analyze student academic performance and identify factors that influence student success. The project focuses on attendance, study hours, assignment scores, and final examination marks.

## Dataset
The dataset contains student information including:
- Student ID
- Attendance Percentage
- Study Hours
- Assignment Scores
- Final Marks
- Grade

## Technologies Used
- Python
- SQL
- Data Analytics

## Methodology
1. Data Collection
2. Data Cleaning
3. Data Storage using SQL
4. Data Analysis
5. Data Visualization
6. Result Interpretation

## SQL Analysis Performed
- Average Marks Calculation
- Top Performing Students
- Low Attendance Analysis
- Grade Distribution Analysis

## Findings
- Students with higher attendance generally achieved better marks.
- Increased study hours were associated with improved academic performance.
- Grade distribution helped identify overall student performance trends.
- Data analytics provided insights into factors affecting academic success.

## Conclusion
The project demonstrates how SQL and Data Analytics can be used to analyze educational data and support informed decision-making.
